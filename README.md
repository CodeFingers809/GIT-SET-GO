# GIT-SET-GO

## Workshop Instructions (5 mins)

### Step 1: Create Your File
Create a new file named `yourname.txt` (replace with your actual name)

### Step 2: Add Your Details
Add the following information to your file:
```
Name: [Your Full Name]
Class: [Your Class/Year]
Rating: [Out of 5]
Feedback: [What did you think could have been improved]
```

### Step 3: Make a new branch and Commit Your Changes
```bash
git branch yourname
git add yourname.txt
git commit -m "Add [yourname] details"
git checkout main
git merge yourname
git push -u origin yourname
```

### Step 4: Make a pull request
Go to github and create a pull request from your branch

That's it! You've made your first contribution.
